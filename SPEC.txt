The Plaintext Guardrail (Pre-Push Hook)

To satisfy Requirement 4 ("ensure plaintext is never pushed"), create a Git hook that intercepts every push and strictly verifies the destination URL.

Create .git/hooks/pre-push and make it executable (chmod +x .git/hooks/pre-push):


#!/bin/bash
REMOTE_URL="$2"

if [[ "$REMOTE_URL" != gcrypt::* ]]; then
    echo "=========================================================="
    echo "FATAL SECURITY ERROR: Remote URL is not encrypted!"
    echo "Attempted to push to: $REMOTE_URL"
    echo "Push aborted to protect plaintext notes."
    echo "=========================================================="
    exit 1
fi

exit 0


If the gcrypt:: prefix is ever accidentally removed from your Git config, this script will immediately block the push.
